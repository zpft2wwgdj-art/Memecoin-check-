Status: not configured – needs a backend. Each alert has a “Send to Telegram” button that works without any setup. Automatic push needs a tiny relay so your bot token never sits in this page.

Relay setup (Cloudflare Worker)

1) Create a bot with @BotFather. 2) Create a Worker and add secrets BOT_TOKEN and CHAT_ID. 3) Paste this code, deploy, and put the Worker URL above.

const cors={'access-control-allow-origin':'*','access-control-allow-headers':'*'};
export default{async fetch(r,env){
if(r.method==='OPTIONS')return new Response(null,{headers:cors});
const{text}=await r.json();
await fetch(`https://api.telegram.org/bot${env.BOT_TOKEN}/sendMessage`,{method:'POST',headers:{'content-type':'application/json'},body:JSON.stringify({chat_id:env.CHAT_ID,text})});
return new Response('ok',{headers:cors})}}
